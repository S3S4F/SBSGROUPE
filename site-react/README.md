# SBS-GROUP - Site Web React Modern

> Version moderne et professionnelle du site web SBS-GROUP construite avec React, TypeScript, Tailwind CSS et Framer Motion.

## 🚀 Technologies

- **React 18** + **TypeScript** - Framework UI avec typage statique
- **Vite** - Build tool ultra-rapide avec HMR
- **Tailwind CSS v3** - Framework CSS utility-first
- **React Router** - Navigation SPA
- **Framer Motion** - Animations fluides et professionnelles
- **React Icons** - Bibliothèque d'icônes complète

## 📁 Structure

```
src/
├── components/
│   ├── common/      # Card, Button, SectionTitle
│   └── layout/      # Header, Footer
├── pages/          # 8 pages complètes
├── layouts/        # MainLayout
└── assets/         # Images, fonts
```

## 🎨 Design

- **Couleur primaire**: `#3871c1` (Bleu SBS)
- **Couleur secondaire**: `#f39c12` (Orange)
